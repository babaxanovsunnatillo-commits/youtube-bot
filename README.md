# YouTube Bot - Инструкция

## Что делает система автоматически каждый день в 9:00:
1. Находит trending тему для США
2. Пишет скрипт через Ollama
3. Создаёт озвучку (человеческий голос)
4. Делает слайды и видео
5. Сохраняет в C:\Projects\youtube\output\video.mp4

## Что нужно делать вручную:
1. Открыть C:\Projects\youtube\output\video.mp4
2. Проверить качество
3. Загрузить на YouTube вручную
4. Добавить описание и теги

## Важно - держи включённым:
- Компьютер в 9:00
- Ollama (запускается автоматически)
- Интернет

## Команды:
- Запустить вручную: python C:\Projects\youtube\main.py
- Проверить задачу: schtasks /query /tn "YouTube Bot"
- Папка с видео: C:\Projects\youtube\output
